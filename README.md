# 📊 Vrinda Store Sales Analysis | Excel Dashboard

An interactive Excel dashboard project for exploring Vrinda Store's 2022 sales data, customer demographics, order status, regional performance, and sales channels.

## 📌 Project Overview

This project uses Microsoft Excel to turn transactional sales data into an interactive dashboard. It brings together data preparation, Pivot Table analysis, charts, and slicers to help explore sales and order patterns.

**Learning resource and project inspiration:** This project was created while following the Vrinda Store Excel Data Analysis tutorial by **Rishabh Mishra**. Credit and links are provided in the Acknowledgements section below.

## 🎯 Objectives

- Compare monthly sales and order volumes.
- Explore sales distribution by gender.
- Review order statuses, including delivered, cancelled, refunded, and returned orders.
- Compare sales across states.
- Explore orders by age group and gender.
- Compare sales channels.
- Build an interactive dashboard with filters.

## 🧹 Data Cleaning & Preparation

The data preparation workflow covers:

1. **Understanding the dataset:** Reviewing the available columns and the information represented by each field.
2. **Checking data quality:** Inspecting blank cells, potential duplicate records, and inconsistent values.
3. **Reviewing data types:** Checking that dates, numeric fields, and category fields are suitable for analysis.
4. **Standardizing categories:** Reviewing labels such as gender, order status, sales channel, and product category for consistency.
5. **Preparing data for analysis:** Keeping the data in a structured tabular format for Pivot Table analysis.

## ⚙️ Data Processing

### Age Group
Customer ages are grouped into categories such as **Teenager**, **Adult**, and **Senior**, allowing comparisons between customer segments.

### Month
The transaction date is represented by month so sales and order counts can be compared across the year.

These fields support the age-based and month-wise summaries shown in the workbook.

## 📈 Analysis & Visualizations

### 1. Sales vs Orders
A combo chart compares monthly order counts and sales amounts.

### 2. Sales by Gender
A pie chart compares sales attributed to men and women. The displayed dashboard shows approximately **36% for men and 64% for women**.

### 3. Order Status
A pie chart presents the distribution of Delivered, Cancelled, Refunded, and Returned orders. The dashboard displays approximately **92% Delivered**.

### 4. State-wise Sales
A bar chart compares sales across leading states.

### 5. Age and Gender
A clustered column chart compares the distribution of orders across age groups and gender.

### 6. Sales Channels
A chart compares channels such as Amazon, Myntra, Flipkart, Ajio, and Meesho.

## 📊 Interactive Dashboard

The **Vrinda Store Report 2022** worksheet combines the main visualizations into one dashboard.

**Dashboard components:**
- Monthly Sales vs Orders chart
- Sales by gender
- Order-status distribution
- State-wise sales chart
- Age and gender comparison
- Sales-channel chart
- Slicers for **Month**, **Channel**, and **Category**

The slicers allow users to filter the report and explore selected segments of the data. Open the workbook in Microsoft Excel to explore the intended interactive experience.

Based on the values displayed in the dashboard:
